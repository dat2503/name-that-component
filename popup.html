🔍 Name That Component

Point at any UI element on the page and see its component name — ARIA role, native HTML, or the design system it comes from (MUI, Ant Design, Bootstrap, Chakra, shadcn/ui, and more).

Or press Alt+Shift+C on any page.
Click an element to lock it in, Esc to exit.
Runs entirely offline — nothing on the page is ever sent anywhere.
