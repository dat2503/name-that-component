# Changelog

All notable changes are documented here. Versions follow Semantic Versioning.

## 1.3.0 - 2026-08-26

- Detect React, Vue, Angular, and Astro component names through a local
  main-world bridge.
- Show source location, visible text, accessible name, locator, children, and
  render tree when available.
- Improve copied inspection details and activation error handling.
- Remove persistent all-sites access; inspection now uses temporary
  user-triggered tab access only.
