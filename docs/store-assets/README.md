# Store assets

- `screenshot-1280x800.png` is generated from the real extension UI by
  `node scripts/browser-smoke-test.mjs`.
- `small-promo-440x280.png` is generated by
  `powershell -ExecutionPolicy Bypass -File scripts/generate-promo-tile.ps1`.
- `marquee-promo-1400x560.png` is an optional larger promotional tile produced
  by the same script.
- `video-frames/` is generated by the browser smoke test from four actual
  inspector states.
- `demo-video-1280x720.mp4` is generated from those frames by
  `powershell -ExecutionPolicy Bypass -File scripts/generate-demo-video.ps1`.

Regenerate the screenshot whenever the inspector panel changes. Do not edit it
to show behavior the extension does not provide.

The smoke test executes the packaged bridge and content scripts directly in a
temporary local Chrome profile. Chrome headless cannot grant `activeTab` from
a synthetic toolbar/keyboard gesture, so activation itself still needs one
manual check with the unpacked extension.

The current Chrome Web Store listing documentation asks for a YouTube promo
video. Upload the MP4 as an unlisted or public video, then paste its URL in the
Store Listing tab. Do not upload it as private because Store reviewers must be
able to view it.

After generating the extension ZIP and all assets, create one dashboard bundle
with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package-store-assets.ps1
```
