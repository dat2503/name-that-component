# Store assets

- `screenshot-1280x800.png` is generated from the real extension UI by
  `node scripts/browser-smoke-test.mjs`.
- `small-promo-440x280.png` is generated by
  `powershell -ExecutionPolicy Bypass -File scripts/generate-promo-tile.ps1`.

Regenerate the screenshot whenever the inspector panel changes. Do not edit it
to show behavior the extension does not provide.

The smoke test executes the packaged bridge and content scripts directly in a
temporary local Chrome profile. Chrome headless cannot grant `activeTab` from
a synthetic toolbar/keyboard gesture, so activation itself still needs one
manual check with the unpacked extension.
