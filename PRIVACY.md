# Privacy Policy

**Effective date:** August 26, 2026

Name That Component does not collect, transmit, sell, or share personal data.
It has no analytics, advertising, tracking, accounts, remote services, or
network requests.

When you explicitly activate the extension on a page, it reads that page's DOM
and framework metadata locally to identify the selected UI element. The result
is displayed only in the page. If you choose **Copy details**, the result is
written to your clipboard. Page content and results are not stored by the
extension and never leave your browser.

The extension uses these permissions:

- `activeTab`: temporary access to the current tab after you invoke the
  extension.
- `scripting`: injects the local component-inspection scripts into that tab.

The extension requests no persistent website access and uses no remote code.

Changes to this policy will be published in this repository. Questions or
privacy concerns can be reported through the repository's issue tracker.
